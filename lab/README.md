# Lab IDS

```bash
./lab.sh up      # tout démarrer
./lab.sh down    # tout arrêter
```

Si les gros fichiers (images `*.qcow2`, dossier `elk/`) ne sont pas à la racine du dépôt,
copier `lab.conf.example` en `lab.conf` et y indiquer `IDS_HOME` (fichier non versionné).

Prérequis, fonctionnement et dépannage : [../docs/00-lancer-le-lab.md](../docs/00-lancer-le-lab.md)
